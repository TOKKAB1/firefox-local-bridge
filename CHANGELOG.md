# Changelog

## 0.2.0 — 2026-10-24

- User-selected access duration: presets, custom minutes/hours/days (up to 365 days), or until manually stopped.
- Change the current session duration without disconnecting it.
- Assistant duration requests with an explicit reason and popup approval; denial, cancellation and expiration cannot extend access.
- Timers handle long durations without overflowing the platform timeout limit.
- Popup language selector: English, Romanian and Russian. Remember language, preferred scope and duration, never the access grant or private-window opt-in.
- Guided Windows setup, automatic local Codex MCP configuration with backup, Unicode-path support and packaged-app registration troubleshooting.
- Prebuilt Windows server bundle, third-party notices and a separate source archive for GitHub.
- Offline start guide in three languages and update/uninstall instructions.

## 0.1.0 — 2026-10-24

- Initial Firefox extension, authenticated native host and MCP integration.
- Live connection, browser-scope tab listing and page read verified in a real user session.
- Windows packaged-app registry/runtime sharing and Cyrillic-path fixes.
