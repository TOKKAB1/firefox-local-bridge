Firefox Local Bridge · v0.2.0

Conectează Firefox la asistentul tău.

Tu alegi filele, durata accesului și fiecare acțiune pe care o permiți.

1Pregătește programul

Folosește arhiva Windows, extrage-o într-un dosar permanent și deschide Setup-Windows.cmd din Explorer. Nu trebuie administrator. Programul detectează Node.js, înregistrează componenta Firefox și pregătește conexiunea Codex.

Dacă lipsește Node.js, instalează versiunea 24 LTS de pe site-ul oficial și rulează din nou instalarea. Arhiva Windows include bibliotecile; nu trebuie să tastezi comenzi de instalare.

2Încarcă extensia în Firefox

  1. Deschide about:debugging#/runtime/this-firefox în Firefox.
  2. Apasă Load Temporary Add-on / Загрузить временное дополнение.
  3. Selectează extension/manifest.json din acest dosar.

Firefox trebuie să fie versiunea 140 sau mai nouă. Instalarea temporară se repetă după repornirea Firefox. Un viitor pachet semnat de Mozilla va permite instalare permanentă. Nu dezactiva verificarea semnăturilor.

3Conectează asistentul

Repornește complet aplicația ChatGPT/Codex. Instalarea pregătește intrarea firefox_local_bridge în configurația Codex locală, cu o copie de rezervă a setărilor existente.

Pentru alt client MCP sau pentru valorile exacte ale conexiunii, deschide setările generate pentru calculatorul tău după instalare. Folosește STDIO și o limită de așteptare de 120 de secunde.

4Alege accesul

Deschide un site obișnuit, apoi pictograma extensiei. Alege limba, tot browserul sau doar fila curentă, durata și pornește accesul.

  • Durată: 15 minute, 1 oră, 4 ore, 1 zi sau durata ta în minute, ore ori zile.
  • Până îl opresc eu: fără cronometru, până la oprire, deconectare sau repornirea extensiei/browserului.
  • Poți schimba durata în timpul unei sesiuni cu Aplică durata începând de acum.
  • Asistentul poate propune o durată prin firefox_request_duration. Tu confirmi sau respingi cererea din extensie.

Primul mesaj de test: „Verifică Firefox Local Bridge, arată filele disponibile și citește fila activă.”

Dacă apare No such native application, deschide din Explorer .installed/Register-Firefox.reg și confirmă înregistrarea acestei componente. Nu îl importa din interiorul aplicației împachetate. Repornește apoi asistentul și încearcă din nou.

Citirea paginilor folosește accesul activat. Apăsările, completările și navigarea cer confirmare; apare ? pe pictogramă. Pentru ferestre private sunt necesare atât opțiunea extensiei, cât și permisiunea din Firefox. Paginile interne Firefox nu sunt accesibile.

Date: textul citit ajunge în conversație și poate fi procesat de furnizorul asistentului. Proiectul nu are un server propriu în cloud. Oprirea accesului nu anulează o acțiune deja efectuată.

Actualizare: dacă acest dosar este deja configurat și a fost actualizat în același loc, apasă Reload / Перезагрузить lângă extensie în about:debugging, apoi repornește asistentul. Accesul începe oprit; nu trebuie reimportată înregistrarea dacă dosarul nu s-a schimbat.

Dezinstalare: oprește accesul, rulează Uninstall-Windows.cmd din Explorer, apoi elimină extensia și intrarea MCP din asistent.

Connect Firefox to your assistant.

Choose the scope, access duration and every action you approve.

1. Run setup

Extract the Windows release ZIP to a permanent folder and double-click Setup-Windows.cmd from Windows Explorer. Setup registers the Firefox host and adds a local Codex MCP entry, preserving other settings with a backup. No administrator is needed. If Node.js is missing, install Node.js 24 LTS and rerun setup. The Windows release already includes the server dependencies.

2. Load the add-on

In Firefox 140+, open about:debugging#/runtime/this-firefox, choose Load Temporary Add-on and select extension/manifest.json. Temporary add-ons disappear after restarting Firefox. Permanent installation needs a future Mozilla-signed release; do not disable signature enforcement.

3. Restart the assistant

Fully restart ChatGPT/Codex. For another MCP client use the exact paths in the generated connection settings, STDIO and a 120-second tool timeout.

4. Enable access

Open a normal webpage, open the extension and choose whole-browser/single-tab scope and duration. Presets, custom minutes/hours/days and Until I turn it off are supported. Apply a new duration during an active session. The assistant can propose a duration with firefox_request_duration; only your approval applies it.

Test: “Check Firefox Local Bridge, list available tabs and read the active tab.” Every click, fill and navigation needs popup approval; look for the ? badge.

If Firefox reports No such native application, import .installed/Register-Firefox.reg yourself from Explorer, then restart the assistant. Do not import it inside a packaged app.

Manual-stop access still ends on disconnect or browser/extension restart. Private windows need both Firefox permission and the session switch. Internal browser pages are unavailable. Page text becomes assistant context and may be processed by its AI provider. Stopping access cannot undo completed actions.

Update in place: reload the extension in about:debugging and restart the assistant. A new grant is required. Reinstall if you move the folder.

Uninstall: stop access, run Uninstall-Windows.cmd from Explorer, then remove the extension and MCP entry.

Подключите Firefox к помощнику.

Вы выбираете вкладки, время доступа и разрешаете каждое действие.

1. Установка

Распакуйте архив Windows в постоянную папку и запустите Setup-Windows.cmd из Проводника. Он зарегистрирует компонент Firefox и добавит локальную запись MCP для Codex с резервной копией настроек. Права администратора не нужны. Если нет Node.js, установите Node.js 24 LTS и повторите запуск. Библиотеки уже включены в архив Windows.

2. Расширение

В Firefox 140+ откройте about:debugging#/runtime/this-firefox, нажмите Загрузить временное дополнение и выберите extension/manifest.json. После перезапуска Firefox временную установку нужно повторить. Для постоянной установки потребуется подпись Mozilla; не отключайте проверку подписей.

3. Подключение

Полностью перезапустите ChatGPT/Codex. Для другого MCP-клиента используйте STDIO, время ожидания 120 секунд и сгенерированные настройки подключения.

4. Доступ

Откройте обычный сайт, нажмите значок расширения, выберите весь браузер или текущую вкладку и время доступа. Можно задать минуты, часы, дни или Пока я не выключу. Время активной сессии меняется кнопкой применения. Помощник может запросить время через firefox_request_duration, но оно применяется только после вашего подтверждения.

Проверка: «Проверь Firefox Local Bridge, покажи вкладки и прочитай активную страницу». Каждое нажатие, заполнение и переход нужно подтвердить в расширении; появится значок ?.

При ошибке No such native application откройте .installed/Register-Firefox.reg из Проводника, подтвердите регистрацию и перезапустите помощника.

Доступ без таймера также заканчивается при разрыве связи или перезапуске браузера/расширения. Приватные окна требуют разрешения Firefox и отдельного переключателя. Служебные страницы недоступны. Текст страниц становится контекстом помощника и может обрабатываться поставщиком ИИ. Выключение доступа не отменяет уже выполненные действия.

Обновление на месте: перезагрузите расширение в about:debugging и перезапустите помощника. Если папка не менялась, повторная регистрация не нужна.

Удаление: выключите доступ, запустите Uninstall-Windows.cmd из Проводника, затем удалите расширение и запись MCP.
