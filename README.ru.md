# Firefox Local Bridge — инструкция

Версия **0.2.0**, независимый прототип для Windows. Вы выбираете область и время доступа, а действия подтверждаете в расширении.

## Установка

1. Распакуйте **`firefox-local-bridge-v0.2.0-windows.zip`** в постоянную папку и откройте **`START-HERE.html`**. Гид работает без интернета, доступны русский, румынский и английский языки.
2. Запустите **`Setup-Windows.cmd` из Проводника**. Он зарегистрирует компонент Firefox и добавит локальную запись MCP в настройки Codex с резервной копией. Права администратора не нужны. Библиотеки включены в архив Windows.
3. Если Node.js не найден, установите **Node.js 24 LTS** с [официального сайта](https://nodejs.org/) и повторите запуск. Установщик также ищет runtime, включённый в Codex.
4. В Firefox 140+ откройте `about:debugging#/runtime/this-firefox`, нажмите **Загрузить временное дополнение** и выберите **`extension/manifest.json`**.
5. Полностью перезапустите ChatGPT/Codex. На обычном сайте откройте расширение, выберите язык, область, время и включите **Доступ помощнику**.

Проверка: **«Проверь Firefox Local Bridge, покажи вкладки и прочитай активную страницу»**.

После перезапуска Firefox временное расширение нужно загрузить заново. Для постоянной установки потребуется подпись Mozilla. Не отключайте проверку подписей.

## Время доступа

- Готовые варианты: 15 минут, 1 час, 4 часа, 1 день.
- **Выбрать время**: целые минуты, часы или дни, от 1 минуты до 365 дней.
- **Пока я не выключу**: без таймера; доступ заканчивается при выключении, разрыве связи или перезапуске Firefox/расширения.
- В активной сессии можно изменить время кнопкой **Применить время с этого момента**.
- Помощник может запросить время с указанием причины. Запрос применяется только после вашего подтверждения в расширении. Помощник не может сам включить остановленную сессию.

Расширение запоминает язык, выбранную область и предпочтительное время. Доступ и разрешение на приватные окна не восстанавливаются автоматически.

## Работа

Можно разрешить весь браузер или только текущую страницу. В режиме одной вкладки навигация и перезагрузка отзывают доступ. Приватные окна требуют отдельного разрешения Firefox и переключателя расширения.

Чтение и прокрутка используют активную сессию. Каждое нажатие, заполнение и переход требуют подтверждения: при значке **?** откройте расширение и выберите **Разрешить** либо **Отклонить** в течение примерно 90 секунд. Остановка не отменяет уже выполненные действия.

## Ошибки и обновление

При **No such native application** откройте **`.installed/Register-Firefox.reg` из Проводника**, подтвердите регистрацию и перезапустите помощника. Не импортируйте файл изнутри упакованного приложения. Для другого MCP-клиента используйте STDIO, 120 секунд ожидания и значения из **`.installed/Connection.html`**.

При обновлении в той же папке перезагрузите расширение в `about:debugging` и перезапустите помощника. При переносе папки сначала удалите старую регистрацию. Одновременно мостом может владеть один MCP-клиент.

Для удаления выключите доступ, запустите **`Uninstall-Windows.cmd` из Проводника**, затем удалите расширение и запись MCP. Исходники сохраняются.

Текст страниц передаётся помощнику и может обрабатываться поставщиком ИИ. У проекта нет своего облачного сервера и телеметрии. Служебные страницы Firefox и некоторые сложные элементы недоступны. Подробности: [SECURITY.md](SECURITY.md).

Архив **`github-source.zip`** — исходники для GitHub; **`windows.zip`** — пакет для пользователей. Новые функции 0.2 проверены автоматически; проверка в реальном Firefox и установка на чистом Windows-аккаунте ещё нужны. Рекомендуемое имя репозитория: **`firefox-local-bridge`**.
